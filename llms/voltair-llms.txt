# Voltair

> Voltair (voltairlabs.com) builds autonomous drone networks for Earth observation, starting with power-utility infrastructure inspection. Its Faraday-1 long-range aircraft and Lighthouse-1 substation charging pads deliver RGB, radiometric-thermal, and LiDAR inspection data on demand. The Voltair API is an organization-scoped infrastructure-inspection platform covering sites, assets, defects, clusters, missions, visits, media, inspections, events, transactions, API keys, and webhooks.

Generated by API Evangelist from the provider's published OpenAPI (https://api.voltairlabs.com/openapi.yaml) and this repo's catalog artifacts on 2026-07-21. Voltair does not publish its own llms.txt (404 at voltairlabs.com/llms.txt and api.voltairlabs.com/llms.txt).
